3. 마른 면봉이나 휴지로 닦는다

4. 액상 맺힘이 있으면 한 번 더 정리한다

5. 청소 후 최소 5분 건조 한다

6. 다시 결합해서 사용한다

접점이 아주 살짝만 젖어 있어도
